## 1. 프로젝트 비전 및 시스템 아키텍처 개요

### 1.1 플랫폼 비전
WebNovel-Studio는 웹소설 작가의 주관적 '감(感)'과 막연한 직관에 의존하던 전통적 창작 방식을 **11단계 공학적 파이프라인**, **4막 6아크 24챕터 정량 구조**, **실시간 메트릭 집필 대시보드**로 체계화한 전문 작가용 AI 페어 라이팅(Pair-Writing) 통합 워크스페이스입니다.

### 1.2 전체 개념도 (Architecture & Conceptual Diagrams)

```
[ 클라이언트 영역 (React 19 + TypeScript + Tailwind CSS) ]
  ├── 1. Top GNB (작품 선택기, AI 제공자 전환, PDF 출력, 옵시디언 내보내기, 사용자 프로필)
  ├── 2. Left GNB (대시보드, 4막 6아크 마스터맵, 24챕터 씬보드, 복선 DB, 100화 기획 생성기)
  ├── 3. 중앙 뷰포트 (Dynamic View Routing)

  │     ├── [View B] 4막 6아크 타임라인 (정량적 100화 시각화)

  │     ├── [View F] 5단계 공학적 소설 생성기 (로그라인 → 100화 씬트리)
  │     └── [View G] AI 페어 라이팅 코치 관제탑 (사이다 지수, 클리프행어 분석)
  └── 4. 레이어 모달 시스템 (PdfExportModal, WorkspaceModal, SettingsModal, NewProjectModal)

                     ▲                       ▲

  ├── /api/ai-coach (문체 진단, 씬 퇴고, 사이다 지수 판정)
  ├── /api/ai/models & providers (Claude / OpenAI / Gemini 동적 쿼리)
  ├── /api/export-obsidian-zip (Obsidian 6대 폴더 마크다운 패키징)
  ├── /api/export-source-zip (프로젝트 소스코드 백업 패키징)
  └── withTimeout (3.5s ~ 5s 지능형 타임아웃 & Fallback 보증)

                     ▲
                     │ (Multi-Model AI Proxy API)
                     ▼
[ AI 파운데이션 모델 엔진 (클라우드 모델 게이트웨이) ]

  └── OpenAI GPT-4o / 6.1 (복선 논리 검증 및 플롯 꼬임 해소)
```

## 2. 11단계 공학적 집필 파이프라인

1. **1단계: 장르 & 핵심 로그라인 수립** (3원소: 주인공 + 핵심 결핍 + 극적 보상)
2. **2단계: 4대 핵심 인물 바이블 구축** (주인공, 적대자, 조력자, 트릭스터의 동기/욕망)
3. **3단계: 세계관 및 3대 철칙 정의** (마법/능력 체계, 사회 계급, 페널티 규칙)
4. **4단계: 4막 6아크 정량 분할** (발단-전개-위기-절정-결말의 회차별 할당)
5. **5단계: 24챕터 씬 비트 트리 설계** (각 챕터당 4~5개 기승전결 씬 분할)
6. **6단계: 씬 단위 복선(Foreshadowing) 심기 & 회수 매핑** (미회수 복선 알림)
7. **7단계: 화당 6,500자 분량 통제 집필** (씬별 1,200~1,800자 블록 결합)
8. **8단계: 씬 엔딩 클리프행어(Hook) 배치** (독자 다음 화 결제 유도선)
9. **9단계: 사이다/고구마 텐션 밸런스 측정** (3화 이상 위기 지속 방지)
10. **10단계: AI 페어 라이팅 교정 및 문체 튜닝** (중복 어휘, 번역투 제거)
11. **11단계: 연재본 패키징 및 다중 플랫폼 동기화** (Obsidian, Word, PDF)

## 3. 디자인 시스템 및 시안 가이드 (UI/UX Blueprint)

### 3.1 컬러 팔레트 & 타이포그래피 토큰
- **배경 베이스**: Slate-900 (GNB/사이드바), Slate-50/Slate-100 (메인 뷰포트)
- **주요 브랜드 컬러**: Blue-600 (`#2563eb`), Blue-500 (`#3b82f6`)
- **보조 포인트 컬러**:
  - Indigo-600 (AI 코치 전용 테마)
  - Rose-500 (복선 미결 경고 및 크리티컬 이슈)
  - Emerald-500 (완료 씬 및 안정성 지표)
  - Amber-500 (옵시디언 및 작업 중 상태)
- **타이포그래피**:
  - 본문: Pretendard (가독성 높은 휴먼 인터페이스 폰트)
  - 코드 및 메트릭스: JetBrains Mono (숫자, 챕터 번호, 토큰 카운트)

### 3.2 핵심 화면 디자인 시안 구조
1. **[시안 1] 메인 관제 대시보드 (View A)**
   - 상단: 4대 핵심 KPI 카드 (총 기획 회차, 완성 챕터 수, 누적 글자 수, 미회수 복선)
   - 중앙: 4막 6아크 진행 게이지 바 및 시각적 달성률
   - 하단: 등록된 소설 프로젝트 캐러셀 카드 및 신규 프로젝트 생성 퀵버튼
2. **[시안 2] 5단계 원클릭 소설 생성 스튜디오 (View F)**
   - 스텝 인디케이터: 1단계(로그라인) → 2단계(인물) → 3단계(세계관) → 4단계(아크) → 5단계(100화 씬트리)
   - AI 추천 아이디어 칩: 클릭 한 번으로 흥행 키워드 자동 주입
   - 단계별 실시간 생성 및 사용자 맞춤 편집기
3. **[시안 3] 24챕터 씬 보드 & 기승전결 집필기 (View D)**
   - 좌측: 챕터 목록 네비게이터 (ch01 ~ ch24)
   - 중앙: 4단 기·승·전·결 칸반형 씬 카드 그리드
   - 우측: 실시간 글자 수 게이지, 클리프행어 점수, AI 코칭 트리거
4. **[시안 4] 복선(Foreshadowing) & 떡밥 추적기 (View E)**
   - 회수율 게이지: 회수 완료율(%) 및 미회수 복선 목록
   - 매핑 테이블: 심은 챕터 ↔ 회수 예정 챕터 ↔ 실제 회수 챕터 추적
5. **[시안 5] AI 페어 라이팅 코치 관제 센터 (View G)**
   - 3단계 감수 모드: [단락 다듬기] / [사이다 지수 강화] / [절정 클리프행어 생성]
   - 차이점(Diff) 비교기 및 한 번의 클릭으로 본문 즉시 적용

## 4. 인터랙티브 버튼 및 사용자 조작 구현 명세서

플랫폼 내 모든 인터랙티브 UI 버튼은 상태 무결성 보장, 낙관적 UI 업데이트, 명확한 피드백을 제공하도록 설계되었습니다.

| 버튼 명칭 | 위치 | 연결된 핸들러 / 함수 | 상호작용 및 동작 메커니즘 | 상태 피드백 |
|---|---|---|---|---|
| **대시보드 HOME** | 좌측 GNB | `onSelectTab('dashboard')` | 전체 소설 프로젝트 목록 및 종합 관제 화면으로 즉시 전환 | 파란색 하이라이트 활성화 |
| **새로운 웹소설 작성하기** | 좌측 GNB / 대시보드 | `onSelectTab('new-project')` | 5단계 공학적 100화 생성기 뷰로 이동, 폼 초기화 | 그라디언트 링 표시 |
| **작품보기 (타임라인)** | 좌측 GNB | `onSelectTab('timeline')` | 4막 6아크 100화 전체 타임라인 맵 표시 | 활성 탭 인디케이터 |
| **작품 개요 (Bible)** | 좌측 GNB | `onSelectTab('overview')` | 5대 기획 문서(세계관, 캐릭터, 문체 등) 뷰 | 활성 탭 인디케이터 |
| **챕터 보드 (Scene Board)**| 좌측 GNB | `onSelectTab('chapter')` | 현재 선택된 챕터의 4단 기승전결 씬 보드 로드 | 진행 상태 뱃지 갱신 |
| **목록 & DB (복선)** | 좌측 GNB | `onSelectTab('lists')` | 복선 회수 추적기 및 미결 과제 체크리스트 전환 | 미결 건수 카운트 뱃지 |
| **기획서 PDF 뷰어** | 좌측 GNB / Top GNB | `setIsPdfModalOpen(true)` | A4 규격 출력용 기획서 & 디자인 시안 모달 팝업 | Backdrop 블러 및 모달 |
| **워드(.doc) 다운로드** | 좌측 GNB / Top GNB | `exportToWordDoc(activeProject)` | 전체 100화 기획서를 MS Word 호환 HTML Blob으로 패키징 후 다운로드 | 파일 다운로드 시작 |
| **옵시디언 워크스페이스** | 좌측 GNB / Top GNB | `setIsWorkspaceModalOpen(true)` | 옵시디언 6대 폴더 트리 브라우저 및 ZIP 내보내기 팝업 | 트리 탐색기 모달 |
| **설정 (AI 모델/API)** | 좌측 GNB / Top GNB | `setIsSettingsModalOpen(true)` | Gemini/Claude/ChatGPT API 키 등록 및 모델 선택 모달 | 모달 팝업 |
| **PDF 즉시 저장 / 인쇄** | PDF 모달 상단바 | `window.print()` | `@media print` 스타일 적용하여 A4 규격 PDF로 즉시 인쇄/저장 | 브라우저 인쇄 대화상자 |
| **Obsidian ZIP 다운로드** | 옵시디언 모달 | `handleDownloadZip()` | 서버 `/api/export-obsidian-zip` 호출, 6대 폴더 ZIP 수신 | 로딩 스피너 및 다운로드 |
| **AI 생성 버튼 (1~5단계)** | 5단계 소설 생성기 | `handleGenerateStep(n)` | 서버 백엔드 AI 파이프라인 프록시 호출, 결과 자동 매핑 | 스켈레톤 로딩 애니메이션 |
| **다음 단계 진행** | 5단계 소설 생성기 | `handleNextStep()` | 현재 단계 데이터 검증 후 다음 기획 스텝으로 전환 | 상단 스텝 프로그레스바 |
| **AI 씬 본문 적용** | AI 코치 뷰 | `handleApplyAiTextToScene()` | AI가 생성/퇴고한 텍스트를 해당 씬에 즉각 치환 반영 | 성공 토스트 및 단어수 갱신 |
| **새 프로젝트 생성** | 프로젝트 카드뷰 | `handleCreateNewProject()` | 템플릿 기반 새 소설 생성 및 로컬스토리지 영구 저장 | 대시보드 리스트 추가 |
| **프로젝트 전환 셀렉트** | Top GNB / 사이드바 | `handleSelectProject(id)` | 선택한 소설의 데이터(인물, 아크, 복선, 씬) 전역 동기화 | 모든 뷰 일괄 리렌더링 |

## 6. 서버 안정성 및 API 가용성 보증 (Resilience)

1. **Vite HMR WebSocket 비활성화**:
   - `server.ts`의 `createViteServer`에서 `server: { middlewareMode: true, hmr: false }` 설정으로 클라우드 프리뷰 컨테이너의 WebSocket 충돌 원천 차단.
2. **타임아웃 프로텍션 (`withTimeout`)**:
   - 상위 AI API 통신 지연 시 무한 로딩을 방지하도록 3.5초~5초 내에 지능형 폴백 응답을 제공하여 프론트엔드가 항상 중단 없이 작동하도록 보장.
3. **데이터 무결성 검증기 (`ensureProjectIntegrity`)**:
   - 브라우저 로컬 스토리지에 저장된 프로젝트 객체가 손상되거나 누락된 필드가 있을 경우 100화 기본 템플릿 제원을 기반으로 자동 마이그레이션 복구.
