## 3. 남은 알려진 문제

- `ALL_CHAPTERS_DATA`가 프로젝트 간 공유 객체다. 이번 적용 경로는 불변 업데이트라 영향이 없지만 다른 편집 경로는 점검이 필요하다.
- AI API 키는 브라우저 `localStorage`에 있다. 서버 보관 방식은 별도 설계가 필요하다.
- 화면 제목 등에 "100화 / 4막 / 6아크"가 하드코딩되어 있다 (D-1~D-4 확정 후 단일 기준 파일로 이동).
- `NewProjectPage.tsx`(약 144KB) 분리 필요. 테스트 코드 없음.
- 기획안 실패 시 클라이언트의 기본 템플릿 예시(`GENRE_PROPOSALS`)를 쓰며 토스트로만 표시한다. 카드 단위 "예시" 배지는 추후 추가.
- Git 푸시는 앱 소스 저장소 대상이다. 원고 백업(S-05)은 마크다운 묶음 내보내기·가져오기로 별도 구현해야 한다.
